# 第 5 章 时序数据可视化

> 时间有五个属性：有序、连续、周期、独立于空间、有结构。同一组数据，用折线、日历还是螺旋来画，取决于你想让读者看见"趋势"、"周期"还是"叙事"。

## 5.1 时间属性

> 画时序图之前，先把"时间"这件事拆开看。

### 五个核心属性

| 属性 | 含义 | 对设计的约束 | 忽略后的后果 |
|---|---|---|---|
| 有序性 | 两个事件有先后，且与因果相连 | x 轴必须按时间排序 | 散点错位成噪声，趋势读不出来 |
| 连续性 | 两个时间点之间总存在另一个时间点 | 连续数据才能连线；离散事件用阶梯/点 | 离散状态被连成"连续变化" |
| 周期性 | 季节、昼夜、周循环 | 可用循环时间域（日历、螺旋） | 季节趋势被线性轴"抹平" |
| 独立于空间 | 时间与空间相关，但通常分开处理 | 时间只占一个轴，不混用空间坐标 | 双轴混读，因果关系被误导 |
| 结构性 | 年/月/日/时/分/秒，自然分割 + 人为定义 | 闰年、月末、工作日/周末要特殊处理 | 跨月、跨年、闰日出现错位 |

### 属性 → 图表选择

| 你想让读者看到 | 优先选择 | 原因 |
|---|---|---|
| 长期趋势 | 折线图 / 面积图 | 线性时间域最直观 |
| 周内规律、节假日异常 | 日历热图 | 星期对齐，异常一眼可见 |
| 年度周期、循环节律 | 螺旋图 / 极坐标 | 每个回路 = 一个周期 |
| 多角色/多事件的叙事 | Storyline | 线的聚散表达关系变化 |
| 精确的单点读数 | 折线 + 点 + 提示框 | 位置通道最准 |

```js
// 时间解析：不要依赖 new Date("2007/8/15") 的浏览器差异
const parse = d3.timeParse("%Y-%m-%d");
const date = parse("2024-03-01");        // 明确、可移植
const fmt = d3.timeFormat("%Y 年第 %j 天");
```

> **易错点**：`new Date("2024-03-01")` 按 UTC 解析，而 `new Date("2024/03/01")` 按本地时区解析。跨时区展示时，同一天可能变成前一天。统一用 `d3.timeParse` 或 ISO 字符串 + `timeParse`。

## 5.2 标准时间可视化（折线图）

> x 轴 = 时间，y 轴 = 度量。它是最常见、也最容易被画错的时序图。

### 你的原案例

法国人名 1900–2020 年的使用频率（Marie / Jean / Camille）。原始页面附带词云、鼠标高亮和时间段筛选。

### 折线图的三条设计规则

1. **时间轴按真实间隔**：用 `scaleTime`，不要用序号。1900→1950 与 1950→2020 的宽度应该反映真实年数。
2. **点数决定平滑方式**：≤50 点用 `curveLinear`；50–500 点用 `curveMonotoneX`；>500 点考虑面积或箱形聚合。
3. **交互服务于读数**：hover 显示精确值，brush 选择时间段，双击复位。

```js
const x = d3.scaleTime()
  .domain(d3.extent(data, d => d.date))
  .range([0, width]);

const y = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.value)]).nice()
  .range([height, 0]);

const line = d3.line()
  .x(d => x(d.date))
  .y(d => y(d.value))
  .curve(d3.curveMonotoneX);

svg.append("path").datum(data).attr("d", line)
  .attr("fill", "none").attr("stroke", "var(--cinnabar)");
```

> **常见错误**：把多年数据按"月份序号 1–12"堆叠，跨年时折线会从 12 月直接连回 1 月，形成一条不存在的"断崖"。跨年数据必须保留真实日期。

## 5.3 日历热图（van Wijk）

> 以"周 = 列、星期 = 行"排列全年数据，把周期性和异常同时显示出来。

### 布局算法

- 每个日期计算它在年内的"周序号"和"星期几"；
- x = 周序号，y = 星期几，颜色 = 数值；
- 月份之间画分隔线，比 7×53 的网格更容易定位；
- 颜色用顺序型 colormap（如 Viridis），不要用彩虹。

```js
// 周序号与星期几：以周一为一周起点
const week = d3.timeWeek.count(d3.timeYear(date), date);
const weekday = (date.getDay() + 6) % 7;   // 周一=0 … 周日=6

const x = d3.scaleLinear().domain([0, 53]).range([0, width]);
const y = d3.scaleBand().domain(d3.range(7)).range([0, height]);
```

### 月份分隔线的巧妙判断

不要按"每月 1 日"画线，而是比较**上一格与当前格是否同月**：

```js
const isMonthDivider = (d, i) => i > 0 &&
  d.getMonth() !== data[i - 1].getMonth();
```

这样无论数据从周几开始、月份长度如何变化，分隔线都准确落在"月份切换的那一格"。

> **设计要点**：每周从周一还是周日开始，会改变"周末"在视觉上的位置。中国习惯周一，美国习惯周日，团队内要统一并在图注里说明。

## 5.4 周期时间可视化（阿基米德螺旋）

> 把时间沿圆周排列：每转一圈 = 一个周期。螺旋 = 圆 + 持续展开。

### 为什么用螺旋

折线擅长"趋势"，不擅长"周期"——同一季节的两年数据在折线上隔得很远。螺旋把相同相位排在同一条射线上，季节规律立刻显形。

阿基米德螺旋：`r = a + bθ`，每转一圈半径增加常量 `b`，等速展开。

```js
const theta = (dayOfYear / 365) * Math.PI * 2;
const turn = yearIndex;                    // 第几年
const r = r0 + turn * gap;                 // 每圈外扩 gap
const x = cx + r * Math.cos(theta);
const y = cy + r * Math.sin(theta);
```

原文档还有一个精妙处理：用 `Δθ = boxSize / √(b² + r²)` 动态调整每格的角宽，让每个日期扇环的**弧长**近似相等，避免外圈格子被拉长。

### 适用与取舍

| 适合 | 不适合 |
|---|---|
| 年/季节/周的循环规律 | 没有周期、或周期很长 |
| 多年同一相位的对比 | 需要精确读取单点数值 |
| 呈现"节律"而非"趋势" | 事件稀疏、时间间隔不均 |

## 5.5 Storyline 时间线（侏罗纪公园）

> 多角色叙事：每条线 = 一个角色 / 组织 / 进程；线的聚散 = 关系的变化。

### 三大元素

1. **时间尺度映射**：电影时长 → SVG 宽度，x 轴严格按比例对齐；
2. **生命线**：`curveCatmullRom.alpha(0.5)` 的样条，线的靠拢表示相遇/冲突，分开表示分离；
3. **事件层**：半透明圆 + 文字，标注关键转折点。

```js
const line = d3.line()
  .x(d => x(d.time))
  .y(d => y(d.y))
  .curve(d3.curveCatmullRom.alpha(0.5));

g.selectAll(".character").data(characters).join("path")
  .attr("d", d => line(d.points))
  .attr("stroke", d => d.color)
  .attr("fill", "none");
```

### 为什么用 Catmull-Rom 而不是 monotoneX

`monotoneX` 保证不过度弯曲，但会让线"太直"，失去叙事的"河流感"。Catmull-Rom 的张力系数 `0.5` 是经验值：既能自然流动，又不会在控制点之间震荡。

> **应用场景**：电影分析、案件多人时间线、体育比赛互动、项目任务交接。Storyline 的重点不是"精确读数"，而是"关系如何随时间变化"。
